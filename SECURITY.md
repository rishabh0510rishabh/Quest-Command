## Reporting a Vulnerability

We take the security of our software seriously. If you believe you have found a security vulnerability in Quest Command, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them via email to [rishabh0510rishabh@gmail.com](mailto:rishabh0510rishabh@gmail.com). You should expect a response within 24 hours.

If you have not received a response within 48 hours, please feel free to follow up.
